# Classroom Feedback Skill

一个面向英语课堂老师的课堂点评 Skill。上传课程界面、教材页面或课堂截图，并输入“帮我给图中的小朋友写一个点评”，即可生成一份结构清晰、可以直接发送给家长的中文课堂反馈。

An AI skill that turns English-lesson screenshots and teacher notes into concise, parent-facing classroom feedback in Simplified Chinese.

## 功能特点

- 从截图中识别课程标题、学习主题、词汇、核心句型、语法、自然拼读或阅读内容。
- 按固定结构整理“今日所学、老师引导、课堂表现、改进建议、知识点梳理”。
- 支持补充学生姓名、课堂表现、发音问题、注意力情况和课后练习建议。
- 优先采用老师提供的文字说明，不随意改写或遗漏重要观察。
- 截图信息有限时使用克制、客观的表达，避免虚构准确率、专注度或具体错误。
- 未识别到真实姓名时使用“宝贝”，自动忽略 `Unknown`、课程编号和上课时间等后台信息。

## 输出结构

生成的点评包含以下内容：

1. **今日所学与老师引导**：介绍课程主题、重点词汇或阅读内容、核心句型，以及老师采用的图片观察、提问、示范或造句引导。
2. **课堂表现与改进建议**：用温和、专业的方式总结孩子的课堂参与情况，并给出一至两条具体建议。
3. **知识点梳理**：整理主题词汇、核心句型、英文例句、问答练习，以及相关语法、发音或阅读提醒。

## 使用方法

1. 将此仓库作为 Skill 安装或导入到支持 Skills 的 Agent 中。
2. 上传一张课程界面、教材页面或课堂截图。
3. 输入：

   > 帮我给图中的小朋友写一个点评

4. 如有额外课堂观察，可以直接补充在同一条消息中，例如：

   > 帮我给图中的小朋友写一个点评。今天回答问题比较积极，但长单词的发音还需要多练习。

Skill 会自动结合截图内容与老师补充的信息生成最终点评。

## 输出示例

以下示例以 *I Want Toys* 课程为例：

> 宝贝今天学习了“I Want Toys”主题课程，认识并复习了玩具类英文表达，重点练习了用“I want a…”表达自己想要的玩具。课堂中，老师通过图片观察、提问和句型示范，引导宝贝辨认玩具，并尝试用完整句子表达自己的想法。
>
> 宝贝整体能够跟随老师的节奏参与课堂，在图片提示下逐步练习目标表达。接下来可以更加大胆、主动地开口，减少只回答单个单词的情况，并继续加强词汇发音和记忆。课后可以结合身边物品重复练习核心句型。
>
> 知识点梳理：
>
> - 主题词汇：玩具类单词
> - 核心句型：**I want a + 玩具名称.**
> - 示例：**I want a ball.**
> - 问答练习：**What do you want? — I want a…**
> - 语法提醒：可数名词单数前通常需要使用 **a**。

## 编写原则

- 以截图和老师提供的信息为依据。
- 面向家长表达，语气温和、专业，不过度表扬。
- 改进建议具体、可执行，避免给孩子贴负面标签。
- 默认使用简体中文，并保留必要的英文词汇、句型和例句。
- 正文保持简洁，通常由两个自然段和“知识点梳理”组成。
