# Classroom Feedback Skill

一个面向英语课堂老师的课堂点评 Skill。上传课程界面、教材页面或课堂截图，并输入“帮我给图中的小朋友写一个点评”，即可生成一份结构清晰、可以直接发送给家长的中文课堂反馈。Skill 支持常规课和定级课两种模式。

An AI skill that turns English-lesson screenshots and teacher notes into concise, parent-facing classroom feedback in Simplified Chinese.

## 功能特点

- 从截图中识别课程标题、学习主题、词汇、核心句型、语法、自然拼读或阅读内容。
- 当课程标题包含 `DEMO` 时自动切换为定级课点评，其余课程均按常规课处理。
- 按固定结构整理“今日所学、老师引导、课堂表现、改进建议、知识点梳理”。
- 支持补充学生姓名、课堂表现、发音问题、注意力情况和课后练习建议。
- 每份点评都会明确反馈孩子的课堂状态，让家长了解孩子是否主动回答、能否跟上课堂、是否需要提醒，以及在老师提示后能否继续完成任务。
- 优先采用老师提供的文字说明，不随意改写或遗漏重要观察。
- 截图信息有限时使用克制、客观的表达，避免虚构准确率、专注度或具体错误。
- 未识别到真实姓名时使用“宝贝”，自动忽略 `Unknown`、课程编号和上课时间等后台信息。
- 所有点评控制在 500 字以内，不使用破折号，并采用自然、具体的老师口吻。

## 输出结构

### 常规课

课程标题不包含 `DEMO` 时，生成的点评包含：

1. **今日所学与老师引导**：介绍课程主题、重点词汇或阅读内容、核心句型，以及老师采用的图片观察、提问、示范或造句引导。
2. **课堂状态、表现与改进建议**：具体说明孩子的参与度、回应情况、专注状态、独立思考和对老师提示的依赖程度，再给出一至两条建议。
3. **知识点梳理**：整理主题词汇、核心句型、英文例句、问答练习，以及相关语法、发音或阅读提醒。

### 定级课

只有课程标题包含 `DEMO` 时才会进入定级课模式，输出顺序为：

1. **推荐级别**：先给出一个明确级别，不输出级别范围。
2. **课堂状态和表现较好的方面**：说明孩子是否主动参与、回答是否及时、能否跟上课堂、是否需要老师提醒，再结合听力、表达、发音、词汇、认读和理解等真实表现进行总结。
3. **需要改进的方面**：指出一至两个最需要提升的方向。
4. **老师的具体引导**：重点写明老师教授的内容、句型和知识点，以及使用了哪些方式帮助孩子理解和表达。
5. **课后练习**：给出复习单词、跟读录音、纠正发音和练习完整句子等具体任务。

## 使用方法

1. 将此仓库作为 Skill 安装或导入到支持 Skills 的 Agent 中。
2. 上传一张课程界面、教材页面或课堂截图。
3. 输入：

   > 帮我给图中的小朋友写一个点评

4. 如有额外课堂观察，可以直接补充在同一条消息中，例如：

   > 帮我给图中的小朋友写一个点评。今天回答问题比较积极，但长单词的发音还需要多练习。

Skill 会自动结合截图内容与老师补充的信息生成最终点评。

如果截图标题中包含 `DEMO`，无需额外说明“这是定级课”，Skill 会自动识别并切换结构。

## 输出示例

以下示例以 *I Want Toys* 课程为例：

> 宝贝今天学习了“I Want Toys”主题课程，认识并复习了玩具类英文表达，重点练习了用“I want a…”表达自己想要的玩具。课堂中，老师通过图片观察、提问和句型示范，引导宝贝辨认玩具，并尝试用完整句子表达自己的想法。
>
> 课堂中，宝贝能够在图片提示下辨认玩具并完成跟读，回答问题的意愿不错。遇到需要完整句子表达的问题时，偶尔会先说单个词，在老师给出句型开头后能够继续补充。接下来可以更加大胆、主动地开口，减少只回答单个单词的情况，并继续加强词汇发音和记忆。课后可以结合身边物品重复练习核心句型。
>
> 知识点梳理：
>
> - 主题词汇：玩具类单词
> - 核心句型：**I want a + 玩具名称.**
> - 示例：**I want a ball.**
> - 问答练习：**What do you want? I want a…**
> - 语法提醒：可数名词单数前通常需要使用 **a**。

### 定级课输出示例

当课程标题包含 `DEMO` 时：

> 推荐级别：F
>
> 从今天的定级课来看，宝贝的基础词汇掌握较扎实，能够听懂主要指令并积极参与跟读，绘本理解也比较顺畅。回答事实类问题时反应较快，遇到开放性问题时会先用单词作答，需要老师追问后才能补充完整句子。课堂中，老师结合图片和故事情节，引导宝贝定位关键信息，示范目标句型，再通过分步提问帮助宝贝组织表达。课后建议复习本节课的生词，跟读课堂录音，重点练习老师纠正过的发音和句型，并尝试用完整句子回答相关问题。

## 编写原则

- 以截图和老师提供的信息为依据。
- 面向家长表达，语气温和、专业，不过度表扬。
- 改进建议具体、可执行，避免给孩子贴负面标签。
- 必须写清孩子的课堂状态，使用可观察的行为描述，避免只写“表现不错”或“状态良好”。
- 当孩子需要提醒时，具体说明老师采用了点名、重复问题、图片提示、句型开头或分步追问中的哪种方式，以及孩子在引导后的表现。
- 默认使用简体中文，并保留必要的英文词汇、句型和例句。
- 正文不超过 500 字，不使用破折号，并重点呈现老师的具体教学与引导。
- 常规课通常由两个自然段和“知识点梳理”组成，定级课按照“推荐级别、课堂表现、改进方向、老师引导、课后任务”的顺序展开。
